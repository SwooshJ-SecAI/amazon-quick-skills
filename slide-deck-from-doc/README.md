# Slide Deck from Document

![Category](https://img.shields.io/badge/Category-Content%20Generation-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Converts any document (DOCX, PDF, or Markdown) into a professional PowerPoint presentation with smart layout selection and visual hierarchy. Transforms written content into structured slide narratives.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Trigger Phrases

- "turn this into slides"
- "make a deck from this doc"
- "convert to presentation"
- "document to powerpoint"
- "create slides from this file"

## Tools Orchestrated
