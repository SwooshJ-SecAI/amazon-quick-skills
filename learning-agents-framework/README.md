# Learning Agents Framework

![Category](https://img.shields.io/badge/Category-AI%20Engineering-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Generates structured learning experiences including study packages, notes, quizzes, notecards, and subject-specific learning agents. Supports certification preparation and topic mastery workflows.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Trigger Phrases

- "learn"
- "study"
- "teach me"
- "build a learning package"
- "create study material"
- "generate quizzes"
- "make notecards"
