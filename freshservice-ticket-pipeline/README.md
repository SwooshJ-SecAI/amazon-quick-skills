# Freshservice Ticket Pipeline

![Category](https://img.shields.io/badge/Category-ITSM-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Full Freshservice ITSM integration with five composable Python modules covering the complete API surface. Handles ticket CRUD, notes, search, reassignment, escalation, asset and agent listing, change requests, problems, and releases.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Trigger Phrases

- "create freshservice ticket"
- "close ticket"
- "query tickets"
- "update ticket"
- "add note"
- "search tickets"
- "reassign"
- "escalate"
- "list assets"

## Tools Orchestrated

`run_python`, `file_read`, `file_write`
