# Compliance Automation

![Category](https://img.shields.io/badge/Category-Compliance-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Generates draft compliance policies for SOC 2 Type I/II, ISO 27001, and HIPAA frameworks. Produces evidence collection checklists, control mapping matrices, and gap analysis reports from existing documentation.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Trigger Phrases

- "prepare for SOC 2 audit"
- "generate compliance policies"
- "map controls to framework"
- "audit prep"
- "compliance gap analysis"
- "ISO 27001 readiness"

## Tools Orchestrated

`file_write`, `file_read`, `file_read_pdf`, `file_rag_search`, `run_python`, `web_search`
