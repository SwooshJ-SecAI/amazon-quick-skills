# Onboarding Orchestrator

![Category](https://img.shields.io/badge/Category-Business%20Operations-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Designs and manages end-to-end employee onboarding programs with structured 30/60/90 day plans, buddy assignments, meeting schedules, tool access checklists, and milestone tracking. Adapts plans by role type and seniority.

Built with [Amazon Quick](https://amazon.com/quick).

---

## Trigger Phrases

- "create onboarding plan"
- "new hire checklist"
- "30-60-90 plan"
