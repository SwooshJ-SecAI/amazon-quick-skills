# HTML Deck Builder

![Category](https://img.shields.io/badge/Category-Content%20Generation-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Builds professional HTML slide presentations as single self-contained files with keyboard navigation, speaker notes, and progress tracking. Produces browser-based slideshows that require no external dependencies.

Built with [Amazon Quick](https://amazon.com/quick).

---
