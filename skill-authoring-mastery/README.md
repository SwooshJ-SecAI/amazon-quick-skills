# Skill Authoring Mastery

![Category](https://img.shields.io/badge/Category-AI%20Engineering-blue?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Amazon%20Quick-orange?style=flat-square)

Structured learning pathway for mastering Amazon Quick skill authoring. Covers skill structure (frontmatter, deterministic/agentic steps, triggers, inputs), procedure extraction, evaluation authoring, and the test-improve loop.

Built with [Amazon Quick](https://amazon.com/quick).
